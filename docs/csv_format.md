# fish_log CSV 형식 (39열)

`data_logger_node`가 100 Hz로 쓰는 블랙박스 로그. 파일 위치 `~/ros2_ws/log_csv/`,
파일명 `fish_log_YYYYMMDD_HHMMSS.csv`. (`log_csv/`는 gitignore 대상이라 이 문서만 `docs/`에 둔다.)
2026-08-21부터 39열 (2026-08-18~20 파일은 36열, 그 전은 23열 — 앞쪽 열의 의미는 모두 동일).

## 저장 방식 — 반드시 알고 분석할 것

- **스냅샷 모델**: 콜백은 최신값을 저장만 하고, 10 ms 타이머가 그 순간의 스냅샷을
  한 줄로 쓴다. 즉 한 행은 "같은 순간"이 아니라 **"그 시점까지 도착한 각 토픽의
  최신값"**이다. 열마다 나이가 다르다 (아래 갱신율 참조).
- **시계는 Pi 하나뿐**: nRF는 타임스탬프를 보내지 않는다 (46B 패킷에 시각 필드 없음).
  `Time(s)`는 로거 기동 기준 Pi 경과 초. UART 전송 지연 ≈ 4 ms(상수), 행 내
  열 간 어긋남 최대 ±1행(10 ms).
- **로테이션**: 파일당 200 MB(약 2.4시간)에서 새 파일로 넘어간다. `Time(s)`는
  파일 경계를 넘어 이어지므로 그대로 이어붙여 분석하면 된다.
- **마지막 행은 잘려 있을 수 있다** (정지 순간 쓰다 만 줄). 열 수가 안 맞는 행은 버릴 것.
- **초기값 구간**: 기동 즉시 기록을 시작하므로, 센서가 붙기 전 구간은 초기값
  (0, 서보 1500, BLDC 1000)이 그대로 찍힌다. 실수신 시작 시각은 저널 INFO에 남는다.

## 열 정의

| # | 이름 | 단위 | 출처 (갱신율) | 설명 |
|---|---|---|---|---|
| 1 | Time(s) | 초 | 로거 자체 (100 Hz) | 기동 기준 경과 초. 행 간격 0.01초 |
| 2 | Btn1_Count | 회 | /rc/status (100 Hz) | btn1 짧은 누름 누적 횟수 |
| 3 | Mode | — | /rc/status | 0 = 정상, 2 = 조종기 두절(−9999 센티넬) |
| 4 | AutoMode | — | /filtered/attitude | 0 = 수동, 1 = 자동 (attitude.x의 ±5000 해독) |
| 5–7 | Roll, Pitch, Yaw | 도 | /filtered/attitude (100 Hz) | EKF 융합 자세. ±5000 제거 후 값, Yaw는 btn2 영점 적용. **양수 pitch = 코 아래** (항공 규약 반대) |
| 8–11 | RC_T, RC_R, RC_P, RC_Y | 원시 정수 | /rc/command (100 Hz) | 스틱값. **−9999 = 링크 두절, 무필터 기록** (두절 구간을 눈으로 찾는 용도) |
| 12–15 | M1–M4 | µs | /motor/output (100 Hz) | 좌서보 / 우서보 / 요서보 / 꼬리 BLDC |
| 16 | RPM | rpm | /sensor/tail_rpm (10 Hz) | 꼬리 회전수. 분해능 200 RPM |
| 17–19 | P0–P2_cal | mbar | /sensor/pressure_calibrated (~11 Hz) | 영점 보정 수압(게이지). **죽은 채널 = `nan`** (2026-08-20 이전 파일은 0.0), 웜업 **180초** 전엔 미발행이라 초기값 0.0이 유지된다 |
| 20–22 | T0–T2 | °C | /sensor/pressure_raw (~11 Hz) | 채널별 원시 온도 — 압력 드리프트 진단용 |
| 23 | RSSI | — | /rc/status | 링크 신호 세기. 두절 시 −127 |
| 24–26 | AX, AY, AZ | **g** | /raw/imu_6dof (100 Hz) | 원시 가속도, **칩 축** (REP-103 아님, 정지 시 \|a\|≈1.0) |
| 27–29 | GX, GY, GZ | 도/초 | /raw/imu_6dof (100 Hz) | 원시 자이로, **칩 축**, 바이어스 포함 |
| 30–32 | MX, MY, MZ | µT | /raw/magnetometer (~94 Hz) | 원시 지자기, **보정 전 칩 축** — 새 보정 계수를 오프라인 재적용 가능. ASA ROM 미적용으로 \|m\|이 실제보다 ~30 % 낮음 |
| 33–35 | BiasX, BiasY, BiasZ | 도/초 | /filtered/ekf_status (10 Hz) | EKF 자이로 바이어스 추정, **FLU 몸체 축** |
| 36 | EKF_Flags | 비트 | /filtered/ekf_status (10 Hz) | 아래 비트 표 참조 |
| 37–39 | P0–P2_raw | mbar | /sensor/pressure_raw (~11 Hz) | **영점 전 절대압.** 대기압 ~1013. 죽은 채널·미수신 = `nan`. 17–19열과 나란히 있어 `raw − cal` = EKF가 잡은 대기압 영점이 그대로 복원된다 |

## EKF_Flags 비트

| 비트 | 의미 |
|---|---|
| 0x01 | 초기화 완료 |
| 0x02 | 가속도 갱신 적용됨 |
| 0x04 | 지자기 yaw 갱신 적용됨 (9축 정상) |
| 0x08 | 가속도 기각 (교란 감지) |
| 0x10 | 지자기 기각 (복각/크기 게이트) |
| 0x20 | **지자기 두절 — 6축 폴백 중** |

정상 9축 = 7 (0x01\|0x02\|0x04). 기동 직후 0 → 3 → 7 전이는 정상 (초기화 → 지자기 기준 확보).

## 분석 시 함정 4가지

1. **축 프레임이 열마다 다르다**: AX..GZ·MX..MZ는 칩 축, BiasX..Z와 Roll/Pitch/Yaw는
   FLU 몸체 축. 원시 자이로에서 바이어스를 직접 빼면 틀린다 — 칩→몸체 변환
   `(bx, by, bz) = (−gz, −gx, +gy)` 를 거친 뒤 뺄 것
   (실측 대조: BiasZ −3.06 ↔ 원시 GY −3.0).
2. **저주기 열은 계단(sample-and-hold)이다**: Bias·Flags는 ~10행, 압력·온도는 ~9행씩
   같은 값이 반복된다. 미분하거나 스펙트럼을 보면 안 된다.
3. **같은 행의 자세와 원시 6축은 같은 샘플이 아니다**: 최대 ±1행(10 ms) 어긋날 수
   있다. 구조적인 것이므로 맞추려 들지 말 것.
4. **압력은 두 벌이고 서로 다른 것을 뜻한다**: 17–19열(`_cal`)은 EKF가 잡은 대기압
   영점이 이미 빠진 게이지압이고, 37–39열(`_raw`)은 영점 전 절대압이다. 수심·피토
   차압을 다른 상수로 다시 계산하려면 **반드시 `_raw` 쪽을 쓴다** — `_cal`은 영점이
   섞여 있어 역산이 안 된다. 반대로 그 차이(`raw − cal`)가 곧 그 세션의 영점 값이다.
   (`_raw`는 이름과 달리 드라이버의 IIR을 거친 값이지만, 2026-08-19부터 그 필터가
   임시로 우회돼 있어 현재 파일들은 진짜 무필터다.)
